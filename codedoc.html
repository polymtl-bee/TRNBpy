1. Site data builder

S1_SiteDataBuilder._make_Site(c)

Small function to build a site recap from reading all given B18 geometrics files descriptions. Return a small CSV with recap of surfaces by Subbuilding, Building, Number of floor and enduse.

Args:

c (ClassConfiguration): A ClassConfiguration object containing all path and parameters of tool.

S1_SiteDataBuilder._make_Buildings(c)

Small function to build a an input surface file for every building given as an b18 input file. Should be used for a « real » or detailed or reference approach to get wanted surface for site. Be careful if you model building with only 1 central floor, you must manually update CSV file to match what you really want. Return a small CSV with recap of surfaces by Subbuilding, Building, Number of floor and enduse.

Paramètres:

c – A ClassConfiguration object containing all path and parameters of tool.

S1_SiteDataBuilder._schedules_generator(weekday, saturday, sunday, dayoff=[], holiday=[])

This function takes several daily schedules, for weekdays, saturday, sunday, dayoff and holidays. Then it build an annual based on those schedules values and predetermined dayoff and holiday dates.

Return:

schedule (list): List of the hourly values of schedules during one year.

Args:

weekday (list): daily schedule values for weekday. saturday (list): daily schedule values for saturday. sunday (list): daily schedule values for sunday. dayoff (list): daily schedule values for a typical dayoff. holiday (list): daily schedule values for a typical holiday day.

S1_SiteDataBuilder._get_scheduleList_FromSpacetype(spacetype_dict, c)

This function will recursively parse a json_object, returning every instance of a specific string target. We use this function to detect every schedule used in a JSON spacetype file.

Args:

spacetype_dict (dict): The JSON object we want to parse (so the JSON spacetype file). c (ClassConfiguration): A ClassConfiguration object containing all path and parameters of tool.

S1_SiteDataBuilder._generate_InputSchedule(c, input_schedule_family=['horexA', 'horexB', 'horexC', 'horexG', 'horexD', 'horexK'], input_schedule_subfamily=['occ', 'lum', 'eq', 'dhw', 'cool', 'heat', 'vent'], input_schedule_daytype=['WD', 'Sat', 'Sun'])

This function will read the input schedule file (detected at c.path_ScheduleInput). Then it will create an annual schedule using _schedules_generator() function and daily schedules found in inpout schedule file. Schedules names must follows « Schedule family » + « _ » + « Schedule category » + « Schedule daytype ». For instance: horexA_occSat, horexB_lumSat…

Args:

c (ClassConfiguration): A ClassConfiguration object containing all path and parameters of tool. input_schedule_family (list): Schedule family (for instance: CNEB Schedule G for residential). Used in schedule name definition. input_schedule_subfamily (list): Schedule categories (for instance: occupant schedule, light schedule…). Used in schedule name definition. input_schedule_daytype (list): Schedule daytype identifier (for isntance: WD for Weekday, Sat for Saturday…). Used in schedule name definition.

S1_SiteDataBuilder._update_json_with_trnsys_schedules(file, json_dict, k, time_column='TIME', value_column='VALUES', schedName='')

This function aims to convert a schedule in csv format (list-like) to a TRNBuild schedule. It will retrieve the timeColumn and valueColumn columns from the csv file using pandas and convert it to an annual schedule. Then the schedule definition will be added as a schedule in the spacetype given in json_dict.

Args:

file (str): A string containing the path to the csv file. json_dict (dict): A spacetype JSON definition stored in a dictionary. k (dict): keys equivalence dictionary from ClassConfiguration. time_column (str): The name of the column to look for timestep values. Must be in hours. value_column (str): The name of the column to look for schedule values. Must be in interval [0,1]. schedName (str): The name tu use for the schedule.

Return:

json_dict (dict): The spacetype definition where to add the schedule

S1_SiteDataBuilder._update_json_with_input_schedules(json_dict, k, schedName='')

This function will write the schedule schedName in json_dict JSON spacetype file. No time and values series are given because this schedule is an input in the B18 file. The schedule type will be input so that B18 update will interprete this schedule as an input.

Return:

json_dict (dict): The spacetype definition where to add the schedule

Args:

json_dict (dict): A spacetype JSON definition stored in a dictionary. k (dict): keys equivalence dictionary from ClassConfiguration. schedName (str): The name tu use for the schedule.

3. Noise builder

S3_NoiseBuilder.randomIntervalSelection(ListOfValues, Coef)

This function introduce a random noise from a controlled interval to the values of a specific attribute of eeach zone. This function keep the specific attribute mean constant. For instance, a noise of +- Coef % will be introduced to every zone lighting gains, while keeping the total/mean lighting gain of the building identical.

Args:

ListOfValues (List): A list of all zones nominal value for a specific category. For instance, it could be a list of all nominal values for equipment gains. Coef (Float): Interval coefficient for introducing noise.

Return:

ListOfValues (List): The previous ListOfValues, updated with the noise.

S3_NoiseBuilder.noiseValues(c)

Generate noise for nominal value of zone’s dhw, gains and ventilation, using the previously defined randomIntervalSelection() function. Sum of building radiative, convective and humidification gains are kept constant for the 3 categories (people, equipment, lights)

Args:

c (ClassConfiguration): A ClassConfiguration object containing all path and parameters of tool.

S3_NoiseBuilder.noiseSchedules(c)

Generate noise to schedules. Annual occupancy schedule is read,every changes in occupancy are identified. Then those changes are moved by in an interval +- 2h with a gaussian-like probability. Schedules variation implies differents total electric consumption at the end of the day.

Args:

c (ClassConfiguration): A ClassConfiguration object containing all path and parameters of tool.

S3_NoiseBuilder.noiseTsetpoint(c)

Generate noise on schedule setpoint base value of every residential area for every schedule file. Using interval and wieght:

  • interval = [-3, -2 , -1 , 0 , 1 , 2 , 3 ]

  • weight = [5%, 10%, 10%, 25% , 25% , 15%, 10%]

Args:

c (ClassConfiguration): A ClassConfiguration object containing all path and parameters of tool.

S3_NoiseBuilder.noise(c)

Main function for noise. Will call noise function if precision of occupancy is stochastic.

Args:

c (ClassConfiguration): A ClassConfiguration object containing all path and parameters of tool.

4. Deck builder

This function allows to update a template Deck file with saved configuration and buildings informations. It includes update path to meteo file, path to external schedule file, path to building file. It also includes linking all of the building’s output to different Type25 in deck file. If maximum number of input is reached, then multiples deck are generated until all outputs are linked to one Type25 input.

Args:

B18_InputPath (string): Path to .b18 building file. c (ClassConfiguration): A ClassConfiguration object containing all path and parameters of tool. DCK_TemplatePath (string): Path to .dck template used to write output in. DCK_OutputPathDir (string): Path to output directory where to save updated .dck file. PATH_METEO_FILE (string): Relative path to meteo file. PATH_SCHEDULE_FILE (string): Relative path to schedule file. filename (string): A string containing the name of the output file, without it’s extension (.dck). schedKEY (string): A string of the common identifier found a the begening of every schedule name. Used for importing only specific columns from CSV file. schedFILEUNIT (string): A string of an integer corresponding to the fileUNIT of the CSV (defined in the assign line of CSV import block). PRINTER_MAX_INPUT (int): Maximum number of input allowed per Type25c logger.infoer. If total outputs is greater than PRINTER_MAX_INPUT, multiple deck files will be generated.

The list_output_name and list_output_id are sublist extracted from Type56 list of output to make sure this Type25c doesn’t have too much inputs.

Args:
